# 出荷ゲート構想 — 全体ロードマップ

AIで作ったもの(サイト・チラシ・ロゴ)を「仕事で使える品質」に引き上げて世に出すためのツール群。
コンセプトは一貫して **「AI生成物 → プロ品質の成果物への変換ゲート」**。

## プロダクト3本柱

| # | プロダクト(仮称) | 入力 | 出力 | 課金モデル |
|---|---|---|---|---|
| 1 | **LaunchGuard**(サイト診断・修正) | URL / GitHubリポジトリ | 安全にローンチできる状態+継続監視 | 修正は単発(¥1,980〜)、監視はサブスク(月¥980/サイト〜) |
| 2 | **VectorPack**(ベクター納品データ化) | AI生成画像(PNG) | アウトライン化済み .ai互換 + SVG + 透過PNG + CMYK版のZIP | 単発/クレジット(1件 ¥500目安) |
| 3 | **PrintReady**(印刷入稿PDF化) | AI生成PDF | ネット印刷に入稿できるPDF(300dpi/CMYK/塗り足し) | 単発/クレジット(1件 数百円) |

**着手順**: 1(本命・事業の深さ)→ 2(技術検証が最速・数日でデモ可)→ 3。
共通クレジット制で3つを1ブランドに束ね、相互送客する。

## 共通する課金の型

**「無料で不安を可視化 → 課金で解消 → 解消の証明を発行」**

- 診断・チェックは無料(集客装置)。怖さ(重大N件)までは全部見せる
- 「直す」アクションから課金
- 修正後は再診断して「合格証(バッジ・レポート)」を発行 — 払った結果が目に見える形で残す

## プロダクト1: LaunchGuard(最優先)

### ターゲット
ChatGPT / Claude / v0 / Bolt などでサイトを作り、Vercel / Netlify / GitHub Pages で
公開する(しようとしている)非エンジニア〜駆け出しの個人。
既存のプロ向けセキュリティ製品(Snyk等)は言葉・価格・設定の面でこの層に届いていない。
**差別化の核は「専門用語 → 行動できる日本語」への翻訳と、AI生成コード特有のミスパターン集。**

### 診断の2段構え(法務と心理の両立)

| 段階 | 認証 | できること | 理由 |
|---|---|---|---|
| 外形診断 | 登録なし | 受動的チェックのみ(HTTPS、ヘッダー、HTML内の露出キー等) | ブラウザと同じ通常アクセスの範囲。登録前に価値を体感させる |
| 深い診断 | GitHub OAuth または ドメイン所有確認(タグ設置) | リポジトリ診断、能動的チェック、修正PR | 所有者確認 = 法的な守り + 「弱点情報は本人にしか見せない」保護機能 |

- 診断結果は機密情報として扱う(保管期限・削除ポリシーを初期から明示)
- 「コードは診断後に削除」「結果は◯日で消える」を明記して信頼を作る

### 診断項目(AI生成サイト特化パターン集 = 資産)

1. APIキー等シークレットの直書き・コミット履歴への残留
2. 公開してはいけないファイルの露出(.env / .git / バックアップ / アーカイブ)
3. データベース権限の全開放(Supabase RLS無効、Firebaseルール全開 等)
4. フォームの入力検証漏れ(XSS / インジェクション)
5. セキュリティヘッダーの欠如
6. 依存パッケージの既知脆弱性(継続監視=サブスクの中身)
7. 無認証の管理画面(/admin 等)

### 修正アクション(商品)

- **自動修正PR**: ヘッダー追加、キーの環境変数化+.gitignore、依存更新、CORS設定 など
- **手順書**: コードで直せないもの(漏れたキーの無効化・再発行)まで面倒を見る
- **鉄則**: AIに合否判定をさせない。発見も検証も決定的なスキャナーが行い、
  AIは説明文と修正コードの生成のみ担当。修正後は必ず機械的に再スキャン

### フェーズ計画

| フェーズ | 作るもの | 検証すること | 期間目安 |
|---|---|---|---|
| **P1** | 外形診断エンジン + 結果表示(登録・決済なし) | 「直し方を知りたい」ボタンのクリック率 = 課金意欲の代理指標 | 数週間 |
| **P2** | GitHub連携 + リポジトリ診断 + LLM日本語レポート。修正はまず「手順書」として販売 | 実際に金を払うか(Stripe導入) | +1〜2ヶ月 |
| **P3** | 修正PR自動生成 + 再診断バッジ + サブスク監視(週次スキャン/push毎チェック) | 継続率・解約率 | +2〜3ヶ月 |
| **P4(拡張)** | WordPress健康診断への横展開、AIカンパニーによる監視・修正の全自動化 | 市場の天井 | その後 |

### 技術構成(初期)

- フロント/API: Next.js + Vercel、DB: Supabase(いずれも無料枠から)
- スキャンジョブ: Cloud Run 等の従量課金コンテナで gitleaks / osv-scanner / Semgrep(カスタムルール)を実行
- レポート生成: Claude API(1診断あたり数円〜数十円)
- 決済: Stripe(固定費ゼロ、手数料3.6%)
- **独自開発が必要なのは2つだけ**: ①AI生成コードのミスパターン(Semgrepルール集) ②レポート生成プロンプト。この2つが競合に真似されにくい資産

### 費用感

- P1〜P2: 月¥5,000〜25,000(最大コストはAI開発ツール代。インフラは無料枠+従量で数百円)
- 課金開始時: 特商法表記・規約(雛形自作¥0〜、専門家チェック数万円を一度)。法人化は当面不要
- スケール時: ユーザーあたり原価は月数十円 → 月額¥980の粗利率は極めて高い

## プロダクト2: VectorPack

### 技術方針
- **本命はベクター直接生成**(Recraft等のSVG生成API)。ラスター→トレース(vtracer / Vectorizer.AI API)は補助
- 文字のアウトライン化は opentype.js でフォント→パス変換(完全プログラム化可能)
- .ai互換出力: 現代の.aiは中身がほぼPDF。SVG→PDF変換+メタデータでIllustratorがそのまま開ける
  ファイルをサーバーサイドで生成できる(Adobe契約不要)
- ベクター化に向く絵/向かない絵の判定を正直に見せる(それ自体が機能)

### 検証手順
1. PNG→SVG→PDF互換.ai のパイプラインを実装
2. SVG/PDFレベルの品質確認は Figma で実施
3. 最終確認(Illustratorネイティブで開けるか、After Effectsでレイヤーが生きるか)のみ
   Adobe体験版で一度通す → 以後は自動テストとして固定

### 顧客
Illustratorを持っていないがプロ向け納品データが必要な人
(フリーランス、ココナラ系出品者、Figmaユーザー)。納品のたびに使う = 単発課金でもリピートする。

## プロダクト3: PrintReady

- 課題の正体: ChatGPT出力PDFは中身が72〜150dpiのラスター(画面用)。印刷は300〜350dpi/CMYK/塗り足し3mm/フォント埋め込みが必要
- 機能: 実効解像度判定 → 劣化プレビュー(無料) → アップスケール+CMYK変換+トンボ付与 → 入稿用PDF出力(課金)
- 部品: Ghostscript / pdfcpu / Real-ESRGAN等の超解像。判定ロジックが差別化
- 出口: 個人の単発課金 + 印刷会社・制作会社向けAPI(B2Bサブスク)

## AIカンパニーとの連携

このツール群の運用そのものを自動化エージェントに載せる:

- **監視エージェント**: サブスク顧客のサイトを定期スキャン、新規CVE公表時に影響顧客を抽出
- **修正エージェント**: 検出→修正PR生成→再スキャン→顧客通知 のループを無人実行
- **レポートエージェント**: スキャナー出力を顧客ごとの文脈で日本語レポート化
- 人間(あなた)の役割は、パターン集の育成・価格と訴求の検証・顧客対応に集中

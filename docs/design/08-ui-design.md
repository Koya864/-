# 08. モバイルファーストUI・高級感×CVR最大化デザイン

対応事項: **11. モバイルファーストUI** / **12. 高級感を維持しつつCVRを最大化するデザイン**

## デザイン原則（Apple / Airbnb / Tesla の翻訳）

| 世界観の要素 | 具体的な実装ルール |
|------------|------------------|
| 余白が多い | セクション間 96px(モバイル64px)。カード内パディング24px。1画面1メッセージ |
| 写真主体 | カードは写真が面積の70%以上。物件詳細はフルブリード写真から始まる |
| 高級感 | 色数を絞る: ベース白/オフホワイト + 墨色テキスト + アクセント1色（深いグリーン系 or ネイビー系を推奨。信頼・資産の連想）。金色・赤の多用は不動産チラシ感が出るため禁止 |
| シンプル | 1ページのCTAは実質1つ。装飾ではなくタイポグラフィ（サイズ・ウェイト差）で階層を作る |

- フォント: 見出し・本文とも Noto Sans JP（またはZen Kaku Gothic New）。数字（価格）のみ
  欧文フォント（Inter等）でtabular-nums指定 — 価格の視認性はCVRに直結。
- モーション: フェード+わずかな上方向スライドのみ。バウンス・派手なパララックスは使わない。

## モバイルファースト設計

ターゲット（20〜40代・SEO/SNS流入）はモバイルが7〜8割と想定。**モバイルのデザインを先に確定**し、PCはその拡張とする。

- ブレークポイント: 基本1カラム → 768px〜 カード2列 → 1080px〜 3列 + 余白拡大。
- 物件カードは**縦カード**（写真上・情報下）で統一。横カードはモバイルで写真が小さくなり世界観が崩れる。
- 物件詳細のエントリーCTAは**モバイルでは下部固定バー**（価格 + 「優先購入エントリー」ボタン）。
  スクロール位置に関わらず常時到達可能に。ただし高さは64px以内・背景は半透明白+ブラーで上品に。
- 画像: next/image + AVIF/WebP、カード画像は4:3固定。LCP対象のヒーロー画像はpriority指定。
  **Core Web Vitals(特にLCP・CLS)はSEO要件でもある**ため、画像最適化はデザイン要件として扱う。

## 物件カード（企画書仕様の実装）

```
┌────────────────┐
│                │  写真（4:3、角丸16px）
│   ♡            │  お気に入り（右上、白丸背景）
│ [認定ランクS]    │  写真左下にバッジ（黒地×白文字、小さく上品に）
├────────────────┤
│ 3,280万円       │  価格（最大サイズ・太字）
│ 岡崎市 ○○町     │  所在地（グレー・小）
│ ⾧ 現在12名が検討中│  補助情報 1つだけ（アクセント色・小）
└────────────────┘
```

- 補助情報（`listings.highlight_metric`）は運営が物件ごとに1つ選択。
  デフォルトの自動選択ロジック: エントリー中→検討中人数 / それ以外でお気に入り上位→お気に入り数 / 新着→「新着」。
- カード全体がタップ領域。ホバー時は写真をごく僅かに拡大（scale 1.02）のみ。

## 高級感とCVRの両立 — 「静かな緊急性」の設計

高級ブランドの世界観と、CVRを上げる緊急性・社会的証明は両立できる。
**「煽らないが、事実は伝える」**が原則。

### やること（CVRドライバー）

| 手法 | 実装 | トーン |
|------|------|-------|
| 社会的証明 | 「現在◯名が検討中」を事実ベースで静かに表示 | 小さく・アクセント色・アニメーションなし |
| 希少性 | 「Life Shift認定物件は掲載全体の◯%」を認定説明で伝える | 認定制度自体が希少性の源泉 |
| 締切 | エントリー期限を日付で表示「エントリー受付は6/30まで」 | カウントダウン秒表示はしない（ゲーム性排除） |
| 損失回避 | お気に入り物件のエントリー期限接近を通知（メール/LINE） | 「まもなく受付終了します」まで。「急いで！」は使わない |
| 摩擦削減 | エントリーは3ステップ・SNSログイン・入力は最小限 | — |
| 安心の担保 | 「エントリーは契約ではありません」をCTA直下に常置 | 不安の除去はラグジュアリー領域で最大のCVR施策 |

### やらないこと（ブランド毀損リスク）

- 順位表示・入札演出・「あと◯秒」カウントダウン
- ポップアップ・追いかけモーダル・偽の在庫表示
- 点滅・赤文字・複数バッジの重ね貼り（補助情報1つルールの徹底）

### 信頼要素の配置（このサービス固有のCVR要因）

高額商材のCVRは緊急性より**信頼**で決まる。各物件ページに:

- 認定ランクの意味への1タップ導線（「ランクSとは」→ /certification/）
- 担当宅建士の顔写真・氏名入りコメント（E-E-A-Tとしても機能）
- 「注意点」を隠さず書く — 短所の開示は購入検討層への最強の信頼シグナル

```
[ロゴ]                    [検索] [ログイン]
─────────────────────────────
  大きな1枚写真 + コピー
  「本当に価値のある住まいだけを。」
  [エリア・駅・価格で探す]（検索ボックス1つ）
─────────────────────────────
  Life Shift認定とは（3行 + リンク）
─────────────────────────────
  人気の認定物件（カード横スクロール/グリッド）
  新着（同上）
  エリアから探す（愛知県の市区町村チップ）
─────────────────────────────
  フッター（会社・免許番号・規約・プライバシー）
```

情報量は企画書どおり最小限。「認定物件一覧」はヘッダーとカード群の「すべて見る」から。

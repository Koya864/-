# 10. 法的論点の洗い出し

対応事項: **14. 宅建業法・個人情報保護・利用規約など、実装前に確認すべき法的論点**

> ⚠️ 本ドキュメントは論点の洗い出しであり、法的助言ではない。
> **ローンチ前に必ず不動産法務に明るい弁護士 + 宅建士のレビューを受けること。**
> とくに★印はサービス構造に影響するため、実装前に結論を出す必要がある。

## A. 宅地建物取引業法

### ★A-1. Life Shift自身の免許・取引態様

- 仲介手数料を収受するモデル → **Life Shift（運営会社）は宅建業免許が必須**。
  未取得なら愛知県知事免許の取得（申請〜交付まで通常1〜2ヶ月+営業保証金/保証協会加入）が
  ローンチの前提条件。事務所要件・専任宅建士の配置も確認。
- 広告表示に**免許番号・商号・取引態様（媒介/代理）の明示が必須**。
  → 実装: 全物件ページとフッターに自動表示（`properties.transaction_type` を必須カラム化済み。03参照）。

### ★A-2. おとり広告・誇大広告の禁止（表示規約含む）

不動産ポータル運営で最も摘発が多い領域。

- 成約済み・取引できない物件の掲載継続は**おとり広告**（宅建業法65条・表示規約21条）。
  → 実装で担保: 管理会社の成約即日報告義務（規約）+ 30日ごとの販売継続確認 + 無応答自動停止（05参照）。
  成約後のSEOページ残し（01参照）は「成約済み」明示 + エントリー導線撤去が条件。
- 「不動産の表示に関する公正競争規約」への適合:
  徒歩分数（80m=1分）、面積表記、「格安」「掘出し物」等の禁止用語、必要表示事項（16項目等）。
  → 実装: 掲載前バリデーション（必須表示項目が埋まらないと公開不可）+ 禁止用語のAIチェックをStage1に組込み。
- **「Life Shift認定」「資産価値が高い」等の表現自体の適法性★**:
  優良誤認（景表法5条1号）にならないよう、認定基準の存在・審査プロセスの実在・
  「将来の資産価値を保証するものではない」旨の注記が必要。認定の根拠資料を保存しておく。

### ★A-3. 購入エントリー・優先購入権の法的位置づけ

- エントリーが売買契約の「申込み」と評価されないよう、規約・画面表示で
  「契約の申込みではない」「いつでも撤回可能」「優先権は商談の優先的地位にすぎない」を明確化（04参照）。
- 順位決定ルールの透明化・事前開示（恣意的運用は消費者トラブル・信義則違反リスク）。
- 「オークションではない」ことの実質確保: 価格競争を発生させない（価格固定）設計を崩さない。

### A-4. 媒介契約・重説・契約

- 商談→契約フェーズは通常の媒介業務（媒介契約書面、重要事項説明、37条書面）。
  IT重説・電子契約を使う場合は書面電子化の要件確認。MVPではオフライン運用でよいが、
  **どの時点で誰と媒介契約を結ぶか**（売主側: 管理会社と共同仲介? 買主側: エントリー時? 商談開始時?）は
  事業スキームとして弁護士と確定させる。

## B. 個人情報保護法

- プライバシーポリシー策定・公表（利用目的: 物件紹介・エントリー管理・ローン紹介等を明記）。
- **第三者提供の整理★**:
  - エントリー者情報を売主・管理会社に渡すか → 本設計では渡さない（09参照）ため提供問題を回避。
  - 住宅ローン紹介で金融機関へ渡す場合 → 明確な同意取得UIが必要（チェックボックス・目的明示）。
- 安全管理措置: アクセス制御（RLS）・監査ログ・暗号化。SMS認証で取得する電話番号も個人情報。
- 漏えい時の報告体制（個人情報保護委員会への報告義務要件）を運用マニュアル化。
- Cookie/計測: GA4等の利用をポリシーに記載。外部送信規律（電気通信事業法の外部送信規律の適用有無★
  — 不特定多数向けオンラインサービスは対象になり得るため、送信先一覧の公表を準備）。

## C. 著作権・データ取得関連

- 他社ポータルのスクレイピング不採用の根拠と代替方式 → **02-data-acquisition.md に集約**。
- 管理会社提供の写真・図面: 掲載規約で権利保証 + 利用許諾（サムネイル加工・SEO利用含む）を取得。
- AI生成コメント: 事実誤りは景表法・宅建業法リスクに直結するため、人間確認必須フローを崩さない。

## D. 利用規約体系（作成すべき文書）

| 文書 | 主な内容 |
|------|---------|
| 会員利用規約 | エントリーの法的性質・撤回・優先権ルール・禁止行為・免責 |
| 掲載規約（管理会社向け） | 権利保証・情報の正確性担保・成約報告義務・掲載可否の裁量・掲載料 |
| プライバシーポリシー | 上記B |
| 特定商取引法に基づく表記 | 有料プラン（管理会社向け掲載料）を提供する場合★ |
| 認定制度に関する表示ポリシー | 認定の意味・保証しない事項（社内文書 + 公開説明ページ） |

## E. その他

- **犯罪収益移転防止法**: 宅建業者は特定事業者。契約時の取引時確認（本人確認）義務 → 商談フローに組込み。
- 反社チェック: 管理会社アカウント審査・買主の契約前チェックの運用整備。
- 商標: 「Life Shift Select」の商標調査・出願（類似サービス名の先行登録確認★ — サービス名確定前に）。
- 資金決済・銀行代理業: MVPでは決済を扱わないため非該当。将来ローン紹介を本格化する際、
  **貸金業法上の媒介・銀行代理業該当性★**を確認（紹介料の受け方で結論が変わる）。

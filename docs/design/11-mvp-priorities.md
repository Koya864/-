# 11. MVP機能の優先順位付け

対応事項: **15. MVPで実装すべき機能と後回しにすべき機能の優先順位付け**

## 判断基準

MVPの目的 = **「認定制マーケットに需要があるか」の検証**。検証すべき仮説は3つ:

- H1: 購入検討者は「認定物件だけのサイト」に登録・エントリーするか（買い手需要）
- H2: 管理会社は認定制（落ちる可能性がある）を受け入れて掲載依頼するか（売り手供給）
- H3: エントリー→商談→契約のファネルが成立するか（収益性）

→ **この3仮説の検証に不要な機能はすべて後回し。**
また、法的リスクを塞ぐ機能（10参照）は検証と無関係でも Must とする。

## 優先順位（MoSCoW）

### Must（MVP必須）— 企画書のMVPリスト + 法務要件

| 機能 | 補足 |
|------|------|
| 物件掲載（概要書アップロード → AI抽出 → 確認） | 方式A（02参照）。URL取得(方式B)は含めない |
| 社内審査フロー（審査キュー・承認/保留 + 理由記録） | 06参照 |
| 評価エンジン v1（ルールベース + AI所見） | 重みYAML化だけ将来形に（07参照） |
| 公開サイト: TOP / 物件詳細 / エリア・駅カテゴリ | ISR + JSON-LD + FAQ構造（01参照） |
| 会員登録（メール + Google）+ お気に入り | LINEログインはShould |
| 優先購入エントリー + SMS認証 | 04参照 |
| 優先権付与・繰り上げ管理（管理画面） | 順位算出は自動 + 人間確定 |
| 管理会社ポータル（掲載・ステータス・成約報告） | 05参照 |
| 法務必須実装一式 | 表示事項・成約報告/継続確認・規約同意ログ・audit_logs・RLS |
| GA4 + Search Console + ファネルイベント | 仮説検証の計測がないMVPは意味がない |

### Should（MVP直後・需要シグナルが出たら数週間以内）

- LINEログイン・LINE通知（期限リマインド）
- 保留物件への改善提案の自動送信（MVP期間は手動メールで代替）
- 特徴カテゴリページ（/features/）・購入ガイド記事
- 検討中人数・お気に入り数のカード表示自動選択（MVPは運営が手動設定）
- 管理会社の自社URL取得（方式B）

### Could(Phase2)

- 会員限定「詳細分析」の本格版（MVPでは認定コメント+簡易分析で代替可）
- プレミアム掲載プラン + Stripe決済（MVPは請求書手動）
- 動画・360°ビュー（**MVPから外すことを推奨**: 撮影オペレーションが重く、
  H1〜H3の検証に必須ではない。写真品質の確保に集中する）
- Meilisearch等の検索基盤（MVPはDB検索で十分)
- 東海3県への拡大（is_activeフラグで即応可能な設計済み・03参照）

### Won't（当面やらない）

- 高度なAI分析・価格予測モデル（データが貯まってから。07のロードマップ通り）
- 他社ポータルからの取得(法的リスク。02参照)
- リフォーム・売却サポート・ローン本格連携（収益拡張はPMF後）
- ネイティブアプリ（モバイルWebで十分。08参照）
- 全国展開・多言語

## 企画書MVPリストとの差分（提案）

| 企画書 | 提案 | 理由 |
|-------|------|------|
| 「AIによる情報取得」 | 概要書アップロード方式に限定 | URL方式は法的整理とドメイン検証が必要。検証価値は同じ |
| 「SEOページ生成」 | エリア・駅カテゴリのみ。特徴カテゴリはShould | SEO成果は3〜6ヶ月遅行。MVP判断には効かないが、仕込みが遅いほど損なので基盤だけMust |
| （記載なし） | 動画・360°をMVPから除外 | 上記Could参照 |
| （記載なし） | 法務実装・計測をMustに追加 | 検証の前提条件 |

## 体制・進め方の目安

- 開発: 1〜2名 × 8〜10週間でMust一式は現実的（Supabase + Next.jsテンプレ活用時）。
- **開発と並行して進めるべき非開発タスク**（クリティカルパスになりやすい）:
  1. 宅建免許の確認/取得・弁護士レビュー（10参照）
  2. 管理会社の先行開拓 — **ローンチ時に認定物件が10件未満だとH1検証にならない**。
     先行10〜20社への声かけ・概要書の事前収集を開発第1週から開始する
  3. 認定基準v1の策定（評価軸・重み・85点ラインの根拠づくり）
- 検証期間: ローンチ後8〜12週。KPI例:
  - H1: 会員登録率（物件詳細UU→登録）3%以上 / エントリー発生物件の割合
  - H2: 声かけ→掲載依頼の転換率 / 保留後の再提出率
  - H3: エントリー→商談化率・商談→契約1件以上

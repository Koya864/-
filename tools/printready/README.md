# PrintReady — AI生成PDFの印刷品質診断・入稿変換(プロトタイプ)

「ChatGPTで作ったチラシPDFを印刷すると荒い」問題を解決する。
全体構想は [docs/ROADMAP.md](../../docs/ROADMAP.md) を参照。

## 使い方

```bash
pip install pikepdf img2pdf pillow

# 診断のみ(無料機能の想定)
python3 tools/printready/printready.py check チラシ.pdf

# 入稿用に変換(課金機能の想定)
python3 tools/printready/printready.py fix チラシ.pdf --out 入稿用.pdf
```

## 何をするか

**診断(check)**
- PDF内の画像を取り出し、**実効dpi**(=紙に印刷したときの実質解像度)を計算
- 300dpi以上=印刷品質 / 150dpi前後=甘い / それ未満=画面用と判定
- 色モード(RGB=画面用 / CMYK=印刷用)と用紙サイズ(A4か)も確認
- すべて日本語で「印刷するとどうなるか」を説明

**変換(fix)**
- ページ画像をA4・300dpi相当(2480×3508px)に高解像度化
- RGB → CMYK に変換して入稿用PDFを再生成
- 変換後に自動で再診断し、合格を機械的に確認(「発見→修正→証明」の型)

## 実測(サンプル)

同梱の再現サンプル(ChatGPT風の96dpi RGBチラシ)で:
`96dpi RGB → NG判定 → fix → 300dpi CMYK → 合格判定` を確認済み。

## プロトタイプの割り切りと製品化での差し替え

| 項目 | 現状 | 製品版 |
|---|---|---|
| 拡大 | Lanczos補間(輪郭は多少甘い) | AI超解像(Real-ESRGAN等)に差し替え |
| CMYK変換 | PILの標準変換 | ICCプロファイル(Japan Color)対応 |
| 塗り足し | 未対応 | 3mm塗り足し+トンボ付与 |
| フォント | 画像化前提のため対象外 | テキストPDFのフォント埋め込み確認 |

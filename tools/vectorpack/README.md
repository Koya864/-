# VectorPack — AI生成画像をプロ向け納品データに変換(プロトタイプ)

AIで作ったロゴ・イラスト(PNG/JPG)を、映像・印刷の現場に渡せる
ベクター納品データ一式に変換する。全体構想は [docs/ROADMAP.md](../../docs/ROADMAP.md) を参照。

## 使い方

```bash
pip install vtracer svglib reportlab pillow
python3 tools/vectorpack/vectorize.py ロゴ.png [--out 出力先]
```

## 出力(納品パック)

| ファイル | 用途 |
|---|---|
| `<名前>.svg` | ベクターデータ。Figma・ブラウザでそのまま開ける |
| `<名前>.pdf` | ベクターPDF。印刷・入稿用 |
| `<名前>.ai` | Illustrator互換(中身はPDF互換)。Illustrator / After Effects 用 |
| `<名前>-original.png` | 元画像(正規化済み) |
| `<名前>-vectorpack.zip` | 上記一式 |

## 品質の目安(実測)

- **ベタ塗りのロゴ・フラットイラスト**: ほぼ完全に再現(形状・色とも)
- **白黒ロゴ(実測: LIFE SHIFTエンブレム)**: 2値モードを自動選択。ライオンのたてがみ・円周の文字まで高品質に再現。ファイルも軽量(color 743KB → binary 112KB)
- **グラデーションを含む画像**: 形状は正確だが、色は単色〜段差に簡略化される
- **写真的な画像**: 原理的に不向き。変換前の判定で正直に警告する

変換前に色数からベクター化適性を自動判定して表示する。この「向き不向きを正直に言う」のは
製品でもそのまま機能として出す。
